# AIMIS app downloads

Installation downloads for Agro-Invest's AIMIS workspace and AFC field app.

- [Download the Windows installer](https://github.com/duanehendricks/AIMIS_RELEASE/releases/latest/download/AIMIS-Excel-Import-Setup.exe)
- [Download AFC for Android](https://github.com/duanehendricks/AIMIS_RELEASE/releases/latest/download/AFC-Android.apk)
- [Download the Windows MSI](https://github.com/duanehendricks/AIMIS_RELEASE/releases/latest/download/AIMIS-Excel-Import-Setup.msi)
- [View release details and checksums](https://github.com/duanehendricks/AIMIS_RELEASE/releases/latest)

## Windows

Download the setup executable, open it and follow the installation instructions. AIMIS Excel Import runs on a 64-bit Windows PC and includes its .NET desktop runtime. Sign in with your AIMIS account to check and send approved Excel workbooks. The website and Windows app must use matching workbook transfer versions.

The installer is not Authenticode signed; Windows may show an unknown-publisher notice. Download only from this repository.

## Android

On your phone, download the APK, open it from Downloads and follow the installation prompts. If Android asks, allow your browser to install this app. AFC supports Android 8.0 or later and captures site visits offline. AFC is a direct APK download; it is not listed in Google Play.

To update an existing AFC installation, install over it. **Do not uninstall AFC or clear its storage**, because records are stored on the phone. The 0.1.2 APK uses the same certificate as the previous local AFC build.
